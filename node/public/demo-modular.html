🏭 Component Factory

El ComponentFactory permite crear componentes dinámicamente usando el patrón Factory:

// Crear componente automáticamente ComponentFactory.autoCreate('enrollment'); // Crear con configuración específica ComponentFactory.create('enrollment', 'myContainer', { maxSamples: 6, autoCancel: true });

📝 EnrollmentControl

Componente para enrolamiento de huellas dactilares. Equivalente a DPCtlUruNet.EnrollmentControl:

<div id="enrollment" data-component="enrollment"></div> // Auto-inicialización ComponentFactory.autoInit();

📸 SimpleCaptureControl

Componente para captura simple de huellas con funciones de prueba:

const capture = ComponentFactory.create('simplecapture', 'capture'); capture.on('captured', (data) => { console.log('Huella capturada:', data); });

✅ VerificationControl

Componente para verificación 1:1 e identificación 1:N:

const verify = ComponentFactory.create('verification', 'verify'); verify.setScoreThreshold(60); verify.on('verified', (result) => { console.log('Resultado:', result); });

📋 Información del Sistema

🔌 Adapter Pattern

BiometricAdapter abstrae la comunicación con el backend, permitiendo intercambiar UIs sin afectar la lógica.

BiometricAdapter.connect() BiometricAdapter.on('status', callback) BiometricAdapter.enrollFingerprint(userId)

🏗️ Factory Pattern

ComponentFactory crea e inicializa componentes dinámicamente con configuraciones personalizadas.

ComponentFactory.create(type, containerId, config) ComponentFactory.autoCreate(containerId) ComponentFactory.getActiveComponents()

🧩 Componentes Modulares

Cada componente hereda de BaseComponent y puede ser insertado en cualquier div específico.

class MyControl extends BaseComponent { constructor(containerId, adapter) { super(containerId, adapter); } }
